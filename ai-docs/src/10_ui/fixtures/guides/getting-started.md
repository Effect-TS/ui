---
title: Getting started
summary: Write your first note and watch its activity.
---

Notes keep what you write. Open a note to edit it, and press **Save** when
you're done.

:::Callout{tone="tip"}
Press `Ctrl+S` to save without leaving the keyboard.
:::

```ts
const note = { title: "Groceries", body: "Milk" }
```

Add `Tabs`, a headless list of tabs that each show a panel, whose active tab lives in your Model. It has roving focus with the arrow keys, Home and End, `activateOnFocus`, disabled tabs that stay focusable, tabs drawn as links, `data-activation-direction`, panel enter and exit transitions with `keepMounted`, and an indicator that writes the active tab's position and size as CSS variables.

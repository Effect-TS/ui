Add `@effect/ui-devtools` with `Inspector`, the core of a read-only inspector for the message log. It reads Wire entries into one session per session id, each a ring buffer of 1,000 entries, and answers by `seq`: the entry behind a number or that it's outside the buffer, the entries an entry names and the ones that name it, the Command run an `update` issued, and an instance's Layer builds, Subscriptions, mounts and Command runs. `Inspector.diff` compares two Wire values and reports a placeholder as unknown.

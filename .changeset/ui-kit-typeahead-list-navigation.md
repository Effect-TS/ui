Add `Typeahead` and `ListNavigation`, exported as namespaces, for building custom keyboard-navigable lists and pickers. `Typeahead` provides a Schema-typed buffer (`State`), pure prefix matching with repeated-letter cycling (`step`, `reset`, `isTyping`, `isPrintable`), and a switch-mode reset timer (`WaitReset`, `waitReset`). `ListNavigation` provides orientation- and RTL-aware list stepping (`Orientation`, `Loop`, `available`, `arrowKeys`, `step`, `target`, `isKey`).

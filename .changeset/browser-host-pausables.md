Add `BrowserHost.Pausables`, which `BrowserHost.mount` and `mountEffect` offer each root to, so a tool such as DevTools can show the page at an earlier state. A root's `pause` takes each instance's Model, query results and, optionally, props by path, hides the root's container and paints the tree from them in an `inert` copy beside it. The copy runs no `init`, Command, Subscription, query, element mount, lazy load or Layer build, logs nothing, leaves the head alone and takes no events, and shows a modal dialog or an auto popover as a manual popover, so it never makes the rest of the page inert. While paused, the live root's modal dialogs and auto popovers are closed without reaching its Model, and its document and window listeners don't hear the user's pointer and key input, so a click on the copy doesn't reach the live tree or light-dismiss its popovers. `pause` returns a `Painted`: the paths it had no state for, which start from `init`, and the paths of the instances whose feature slot shows its `fallback` because the copy doesn't build the provided Layer. A paint that fails leaves the page as it was. `resume` removes the copy, shows the live tree, which kept running while it was hidden, and shows the modal dialogs and popovers its Model has open.
